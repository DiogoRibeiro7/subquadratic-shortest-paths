```bibtex

      title={Breaking the Sorting Barrier for Directed Single-Source Shortest Paths},
      author={Ran Duan and Jiayi Mao and Xiao Mao and Xinkai Shu and Longhui Yin},
      year={2025},
      eprint={2504.17033},
      archivePrefix={arXiv},
      primaryClass={cs.DS},
      url={https://arxiv.org/abs/2504.17033},
      note={arXiv:2504.17033v2 [cs.DS]}
}
```

### Plain Text Citation

**Standard Format**:
```
Ran Duan, Jiayi Mao, Xiao Mao, Xinkai Shu, and Longhui Yin. 2025.
"Breaking the Sorting Barrier for Directed Single-Source Shortest Paths."
arXiv preprint arXiv:2504.17033.
```

**With DOI** (if published):
```
Ran Duan, Jiayi Mao, Xiao Mao, Xinkai Shu, and Longhui Yin. 2025.
"Breaking the Sorting Barrier for Directed Single-Source Shortest Paths."
DOI: [to be assigned upon publication]
```

### Paper Access

- **arXiv**: https://arxiv.org/abs/2504.17033
- **PDF**: https://arxiv.org/pdf/2504.17033.pdf
- **Version**: v2 (latest as of repository creation)
- **Submission Date**: April 2025
- **Primary Classification**: Computer Science - Data Structures and Algorithms (cs.DS)

### Abstract

> We present the first deterministic algorithm that achieves O(m log^(2/3) n)
> time complexity for single-source shortest paths on directed graphs with
> non-negative edge weights, breaking the long-standing O(m + n log n) barrier
> established by Dijkstra's algorithm in 1959.

## Frequently Asked Questions

### Q: Do I need to cite both the paper and the implementation?

**A**: It depends on your use case:

- **Using the algorithm conceptually**: Cite only the paper [Duan et al. 2025]
- **Using this code in your software**: Cite both the paper and this implementation
- **Comparing implementations**: Cite all implementations you compare against
- **Extending this code**: Cite both and acknowledge the base implementation

### Q: The paper is on arXiv. What if it gets published in a conference/journal?

**A**: Update your citation to the published version:

```bibtex
@inproceedings{duan2025breaking,
  title={Breaking the Sorting Barrier for Directed Single-Source Shortest Paths},
  author={Duan, Ran and Mao, Jiayi and Mao, Xiao and Shu, Xinkai and Yin, Longhui},
  booktitle={Proceedings of the [Conference Name]},
  pages={[page numbers]},
  year={2025},
  organization={[Publisher]}
}
```

Check the arXiv page for updates on publication status.

### Q: How should I cite if I modified the implementation?

**A**: Acknowledge the base implementation and note your modifications:

```
Our implementation is based on the SSSP Breakthrough Algorithm
implementation [1], with modifications to support [your changes].

[1] SSSP Breakthrough Algorithm Implementation,
    https://github.com/[your-username]/subquadratic-shortest-paths, 2025.
```

### Q: Can I cite specific components (e.g., just FindPivots)?

**A**: Yes, for specific algorithms:

```
We adapt the FindPivots algorithm (Algorithm 1 from [1]) for frontier
reduction in our graph partitioning approach.

[1] R. Duan et al., "Breaking the sorting barrier for directed
    single-source shortest paths," arXiv:2504.17033, 2025.
```

### Q: What about citing the benchmark suite?

**A**: If you use the benchmarking tools:

```
We benchmark our algorithm using the test suite from the SSSP
Breakthrough implementation [1], which includes 40+ graphs with
verified optimal solutions.

[1] SSSP Breakthrough Algorithm Implementation, Test Suite,
    https://github.com/[your-username]/subquadratic-shortest-paths/tests, 2025.
```
